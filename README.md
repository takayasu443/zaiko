## 使い方（現場）

1. **持ち出し**：品目をタップ → 持ち出し先（交配舎・分娩舎…）を選ぶ → 数量（1/2/5/10 のボタンか ± ）→「持ち出しを登録」。「その他」のときだけ名前を入れる
2. **入荷**：上に「入荷待ち」が並ぶので、届いた物の「入荷した」を押す（数が違えば直してから登録）。予定に無い物は下の一覧から品目をタップして「入荷を登録」
3. 名前は任意（設定で選ぶと入荷・棚卸の記録に残る）
4. **在庫**：現在数の一覧。赤い数字＝発注点以下。「棚卸(数を直す)」で実数に合わせられる
5. **履歴**：全員分の記録。間違えたら「取消」（取消の記録も残る）。CSV書き出し可
6. **設定**：名前・Dropbox同期・品目マスタ（追加／発注点／置き場の変更）・バックアップ

ネットが無い場所でも記録でき、電波が戻ったときに自動で送ります。

## データの流れ（共有の仕組み）

```
 各スマホ ──(自分の記録ファイル events/<端末ID>.json を書く)──▶ Dropbox 共有フォルダ
 各スマホ ◀─(他端末のファイルと master.json / expected.json / settings.json を30秒ごと/画面を開いた時に取り込む)──
 PC ──(tools/zaiko_sync.py：発注書 → expected.json、items-default.js → master.json)──▶ Dropbox
```

| ファイル | 内容 |
|---|---|
| events/<端末ID>.json | その端末の記録（持ち出し・入荷・棚卸・取消）。端末ごとに別ファイル |
| events/recovery-*.json | バックアップ復元で持ち込んだ他端末の記録 |
| master.json | 品目マスタ（品名・規格・置き場・発注点・使用間隔・管理する/しない） |
| expected.json | 入荷待ち（発注済み・未着）。入荷済みは60日で自動的に消える |
| settings.json | 共有設定（飼養頭数） |

- 端末ごとに **自分のファイルだけ** を書くので、同時に使っても上書き事故が起きません
- 品目マスタ（master.json）は「新しい更新が勝ち」でマージ、競合時は自動で再試行（3回失敗したらエラー表示）
- 「同期済み」と出るのは、取込・検証・端末保存・送信がすべて終わり未送信が無いときだけ。未送信があれば「未送信あり」、取り込めないファイルがあれば「エラー」と表示します
- 取り込むデータは全件検証してから反映します（壊れたファイルは無視せずエラー表示し、直れば自動で取り込みます）
- Dropbox を設定しない間は、そのスマホの中だけに記録されます（試用はこれで十分）

## 導入手順（管理者：千葉さん向け）

### STEP 1　アプリを https で公開する（全員が同じURLで開けるようにする）　※設定済み

Dropbox / OneDrive の共有リンクは HTML をそのまま表示しないため、**無料の静的ホスティング**に置きます。
おすすめは GitHub Pages（無料・https・URL固定）。Netlify Drop（フォルダをドラッグするだけ）でも可。

GitHub Pages の場合（設定済み。再構築するときの手順）：
1. github.com でアカウント作成 → GitHub CLI（gh）でログイン → `gh repo create zaiko --public`
2. 公開するのは `tools/deploy.py` の PUBLISH に書いた**公開用ファイルだけ**（index.html, core.js, app.js, style.css, sw.js, manifest, items-default.js, icons, README）。
   `招待リンク（社内限定）.txt` や tools/ は公開しません。フォルダ丸ごとアップロードはしないでください。
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 数分後 `https://<ユーザー名>.github.io/zaiko/` で開けます ← これが配布URL

更新するときは `python 在庫アプリ/tools/deploy.py --bump` を実行します（sw.js と app.js の版番号を同時に上げて push）。
各スマホは次に開いたときに「新しいバージョンがあります → 更新」が出て、**利用者が「更新」を押したとき**に入れ替わります（入力中に勝手に切り替わりません）。

### STEP 2　Dropbox 同期を設定する（1回だけ）　※設定済み

1. https://www.dropbox.com/developers/apps → **Create app**（**チームアカウント**でログインして作る。個人アカウントで作るとチーム共有フォルダにアクセスできない）
   - Scoped access → **Full Dropbox**（共有フォルダの中を使うため）→ 名前「CM-Farm-Zaiko-Team」
2. Settings タブ：**Redirect URIs** に STEP 1 の URL（例 `https://xxx.github.io/zaiko/`）を追加
3. Permissions タブ：`files.metadata.read` `files.content.read` `files.content.write` `account_info.read` にチェック → Submit
4. Settings タブの **App key** を控える
5. アプリの「設定 → 接続設定」に App key と 保存先フォルダ（例 `/十勝野ポーク共有/在庫アプリ`）を入れて保存 →「Dropboxでログイン」→ 許可
6. 「接続テスト」で OK が出れば完了。Dropbox 側に `master.json` と `events/` ができます

※ Dropbox アプリは開発モードのままで **50 人まで**接続できます（審査不要）。
※ 保存先フォルダは **チーム共有フォルダの中** にします。Dropbox Business のチームスペースにあるフォルダは API の「パスの基準」をチームスペースにする必要があり、アプリと PC ツールは接続時に自動で判定します（設定画面に「チームスペース基準」と出ます）。
※ 「アプリ側で Dropbox にログインする人」はアプリの所有者（作成したアカウント）だけで済みます。他の人は招待リンクで接続するので、Dropbox アカウントは不要です。

### STEP 3　LINE で配る

> **iPhone のホーム画面アプリについて**
> iPhone では、ホーム画面に追加したアプリは Safari とは別の保存領域を使います。v1.3.1 からは、Safari で招待リンクを開いた状態で「ホーム画面に追加」すれば設定が引き継がれます。
> ホーム画面から開いて「まだ共有されていません」と出た場合は、LINE のメッセージをコピーして 設定 →「招待リンクを貼り付けて接続する」に貼り付けてください。

**A. 招待リンク（おすすめ：相手は Dropbox ログイン不要）**
設定 →「招待リンクを作る」→ LINE で該当者に送る。
相手がタップすると、通常ブラウザで開き、Dropbox 接続と名前リストが自動で入ります。あとは名前を選んで「ホーム画面に追加」。

> 招待リンクには Dropbox の接続情報が入っています。**社内の該当者だけ**に送ってください（LINEグループに流す場合はメンバーを確認）。
> 漏れた疑いがあるときは Dropbox の App 設定で「Revoke」すれば全端末の接続が切れます。

**B. URL だけ送る場合**
設定 →「URLをコピー／共有」。末尾に `?openExternalBrowser=1` が付いており、LINE でタップすると LINE 内ブラウザではなく Safari / Chrome で開きます（LINE内ブラウザではホーム画面追加ができないため）。

**ホーム画面への入れ方**（アプリ内の設定にも表示されます）
- iPhone：Safari の共有ボタン（□↑）→「ホーム画面に追加」→ 追加
- Android：Chrome 右上「⋮」→「ホーム画面に追加」／「アプリをインストール」（画面上のバナーからも可）

**C. 本当に「LINEでタップ → そのまま起動」にしたい場合（次の段階）**
LINE 公式の **LINEミニアプリ（LIFF）** として登録すると、インストール操作なしで LINE の中でそのまま開き、名前も LINE のプロフィールから自動で入ります。
手順：LINE Developers でプロバイダー＋LINEログインチャネル作成 → LIFF アプリ追加（エンドポイントURL＝STEP 1 の URL、サイズ Full）→ 発行された LIFF ID をアプリの設定に入力 → LIFF URL（`https://liff.line.me/xxxx`）を LINE で送る。
このアプリは LIFF ID を入れるだけで対応するように作ってあります。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 他の人の記録が出てこない | 右上の ⟳ をタップ。状態が「エラー」なら設定 → 接続テスト |
| 「端末のみ（未共有）」のまま | Dropbox 未設定。招待リンクをもう一度開くか、管理者に依頼 |
| 在庫数が実際と違う | 在庫 → 品目タップ →「棚卸(数を直す)」 |
| 間違えて登録した | 履歴 → 「取消」 |
| スマホを替えた | 新しいスマホで招待リンクを開くだけ（記録は Dropbox にあるので戻ります） |
