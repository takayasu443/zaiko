# CM農場 在庫アプリ（入出庫）試作版 v1.0.0

専務の発言（2026-11-03 打合せ）をもとに作った、**スマホで「持ち出し」「入荷」をピッと記録する**アプリです。
インストール不要の Web アプリ（PWA）で、ホーム画面に追加すると普通のアプリと同じように使えます。

## 専務の発言 → アプリでの実現

| 発言 | 実装 |
|---|---|
| 携帯から全員アクセスできるように | ブラウザで開くだけ。ホーム画面に追加でアプリ化 |
| 対象は「事務所前」と「コンテナ左右」（ヤマザキコンテナは除外） | 置き場は「事務所前／コンテナ左／コンテナ右／冷蔵庫」の4つ。チップで絞り込み |
| 医薬品と紙タイと冷蔵庫の品ぐらいで | 発注書（アスコ・小田島・アグロ・大竹先生）から 94 品目を初期登録。紙タイも追加済み。種別（薬品／飼料／器具）で絞り込み可 |
| 持ち出した人がスマホでピッピ | 「持ち出し」タブ → 品目タップ → 数量 → 登録（3タップ） |
| 入荷したチェックと、そこから何件持っていったか | 「入荷」タブで入荷数を登録。在庫＝入荷−持ち出し。品目をタップすると履歴が見える |
| 誰が持っていったか分からない・コミュニケーション不足 | 記録に名前・時刻・メモが残る。「履歴」タブで全員分を時系列表示 |
| 最後は発注と紐づくと楽 | 品目ごとに「発注点」を設定すると、下回った品目を仕入先別にまとめた「発注候補」テキストを LINE 等に共有できる |
| スマホで Dropbox に共有できるやつ | Dropbox の共有フォルダを共通サーバーとして使う同期機能を内蔵（→ `Dropbox検証結果.md`） |

## フォルダ構成

```
在庫アプリ/
  index.html            画面
  app.js                アプリ本体（記録・在庫計算・Dropbox同期・LINE/インストール案内）
  style.css             見た目（スマホ縦向き前提）
  sw.js                 オフライン対応と自動更新（サービスワーカー）
  manifest.webmanifest  ホーム画面追加用の設定
  items-default.js      初期の品目マスタ（発注書Excelから自動生成）
  icons/                アイコン
  tools/build_items.py  発注書Excel → items-default.js を作り直すスクリプト
  README.md             この文書
  Dropbox検証結果.md    共通サーバーに Dropbox が使えるかの検証
```

## 使い方（現場）

1. 初回だけ **自分の名前** を選ぶ（富樫・富士・宮本・直人・土居・福田・千葉。追加も可）
2. **持ち出し**：品目をタップ → 数量（1/2/5/10 のボタンか ± ）→「持ち出しを登録」
3. **入荷**：届いた物を見た人が、同じ操作で「入荷を登録」
4. **在庫**：現在数の一覧。赤い数字＝発注点以下。「棚卸(数を直す)」で実数に合わせられる
5. **履歴**：全員分の記録。間違えたら「取消」（取消の記録も残る）。CSV書き出し可
6. **設定**：名前・Dropbox同期・品目マスタ（追加／発注点／置き場の変更）・バックアップ

ネットが無い場所でも記録でき、電波が戻ったときに自動で送ります。

## データの流れ（共有の仕組み）

```
 各スマホ ──(自分の記録ファイル events/<端末ID>.json を書く)──▶ Dropbox 共有フォルダ
 各スマホ ◀─(他端末のファイルと master.json を30秒ごと/画面を開いた時に取り込む)──
```

- 端末ごとに **自分のファイルだけ** を書くので、同時に使っても上書き事故が起きません
- 品目マスタ（master.json）は「新しい更新が勝ち」でマージ、競合時は自動で再試行
- Dropbox を設定しない間は、そのスマホの中だけに記録されます（試用はこれで十分）

## 導入手順（管理者：千葉さん向け）

### STEP 1　アプリを https で公開する（全員が同じURLで開けるようにする）

Dropbox / OneDrive の共有リンクは HTML をそのまま表示しないため、**無料の静的ホスティング**に置きます。
おすすめは GitHub Pages（無料・https・URL固定）。Netlify Drop（フォルダをドラッグするだけ）でも可。

GitHub Pages の場合：
1. github.com でアカウント作成 → 「New repository」→ 名前 `zaiko`（Public）
2. `在庫アプリ` フォルダの中身を全部アップロード（Add file → Upload files）
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 数分後 `https://<ユーザー名>.github.io/zaiko/` で開けます ← これが配布URL

更新するときは同じ手順でファイルを上書きし、`sw.js` の `VERSION` を上げる（例 v1.0.1）と、
各スマホは次に開いたときに「新しいバージョンがあります → 更新」が出て自動で入れ替わります。

### STEP 2　Dropbox 同期を設定する（1回だけ）

1. https://www.dropbox.com/developers/apps → **Create app**
   - Scoped access → **Full Dropbox**（共有フォルダの中を使うため）→ 名前「CM農場在庫アプリ」
2. Settings タブ：**Redirect URIs** に STEP 1 の URL（例 `https://xxx.github.io/zaiko/`）を追加
3. Permissions タブ：`files.metadata.read` `files.content.read` `files.content.write` `account_info.read` にチェック → Submit
4. Settings タブの **App key** を控える
5. アプリの「設定 → 接続設定」に App key と 保存先フォルダ（例 `/十勝野ポーク共有/在庫アプリ`）を入れて保存 →「Dropboxでログイン」→ 許可
6. 「接続テスト」で OK が出れば完了。Dropbox 側に `master.json` と `events/` ができます

※ Dropbox アプリは開発モードのままで **50 人まで**接続できます（審査不要）。
※ 保存先フォルダは **全員が招待されている共有フォルダの中** にしてください（別の場所だと他の人から見えません）。

### STEP 3　LINE で配る

**A. 招待リンク（おすすめ：相手は Dropbox ログイン不要）**
設定 →「招待リンクを作る」→ LINE で該当者に送る。
相手がタップすると、通常ブラウザで開き、Dropbox 接続と名前リストが自動で入ります。あとは名前を選んで「ホーム画面に追加」。

> 招待リンクには Dropbox の接続情報が入っています。**社内の該当者だけ**に送ってください（LINEグループに流す場合はメンバーを確認）。
> 漏れた疑いがあるときは Dropbox の App 設定で「Revoke」すれば全端末の接続が切れます。

**B. URL だけ送る場合**
設定 →「URLをコピー／共有」。末尾に `?openExternalBrowser=1` が付いており、LINE でタップすると LINE 内ブラウザではなく Safari / Chrome で開きます（LINE内ブラウザではホーム画面追加ができないため）。

**ホーム画面への入れ方**（アプリ内の設定にも表示されます）
- iPhone：Safari の共有ボタン（□↑）→「ホーム画面に追加」→ 追加
- Android：Chrome 右上「⋮」→「ホーム画面に追加」／「アプリをインストール」（画面上のバナーからも可）

**C. 本当に「LINEでタップ → そのまま起動」にしたい場合（次の段階）**
LINE 公式の **LINEミニアプリ（LIFF）** として登録すると、インストール操作なしで LINE の中でそのまま開き、名前も LINE のプロフィールから自動で入ります。
手順：LINE Developers でプロバイダー＋LINEログインチャネル作成 → LIFF アプリ追加（エンドポイントURL＝STEP 1 の URL、サイズ Full）→ 発行された LIFF ID をアプリの設定に入力 → LIFF URL（`https://liff.line.me/xxxx`）を LINE で送る。
このアプリは LIFF ID を入れるだけで対応するように作ってあります。

## 品目マスタの作り直し

発注書 Excel が更新されたら、`薬品発注` フォルダで次を実行すると `items-default.js` が作り直されます。

```bash
python 在庫アプリ/tools/build_items.py
```

アプリの設定 →「発注書の初期マスタを追加読込」で、足りない品目だけが追加されます（既存の編集は残ります）。

## 次の段階（発注との連携）

- 発注点を下回った品目 → 仕入先別の発注書 Excel を自動作成（既存の発注書テンプレートに数量を流し込む）
- 発注書から「入荷予定」を作り、入荷タブでチェックするだけで入庫 → 「受け入れ確認リスト」と一体化
- 過去の持ち出し実績から月ごとの使用量を出し、「AIによる発注.xlsx」の発注予想に使う

## 困ったとき

| 症状 | 対処 |
|---|---|
| 他の人の記録が出てこない | 右上の ⟳ をタップ。状態が「エラー」なら設定 → 接続テスト |
| 「端末のみ（未共有）」のまま | Dropbox 未設定。招待リンクをもう一度開くか、管理者に依頼 |
| 在庫数が実際と違う | 在庫 → 品目タップ →「棚卸(数を直す)」 |
| 間違えて登録した | 履歴 → 「取消」 |
| スマホを替えた | 新しいスマホで招待リンクを開くだけ（記録は Dropbox にあるので戻ります） |
